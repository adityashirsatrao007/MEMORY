# Privacy Policy

## Data Collection

MEMORY operates entirely locally. By default:

- **No telemetry** — no usage data is sent anywhere
- **No analytics** — no cookies, tracking, or fingerprinting
- **No external calls** — all vector search runs on your machine via ChromaDB
- **No API key transmission** — keys are stored in `~/.config/global-apikeys/` and never exfiltrated

## freellmapi Proxy

If you use the optional freellmapi proxy, prompts are routed through third-party LLM providers. Review each provider's privacy policy for their data handling. MEMORY does not log or store prompts.

## GitHub Pages

The public website at `adityashirsatrao007.github.io/MEMORY` is hosted by GitHub Pages. GitHub's standard privacy policy applies to site visitors.
