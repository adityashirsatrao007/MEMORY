# The Vibe Coder's Web Design Guide

## 1. Design Aesthetics
- **Glassmorphism:** Frosted glass panels, vivid gradients, backdrop-filter blur.
- **Neumorphism (Soft UI):** Extruded elements from the surface, dual box-shadows, exact color matching.
- **Brutalism:** Raw, thick black borders, primary colors, monospace fonts, zero border-radius.
- **Minimalism:** Whitespace-heavy, typographic hierarchy, monochromatic, no gradients.
- **Bento Grid:** CSS Grid mosaics of varied sizes, Apple-style product showcases.
- **Dark Luxury:** Deep charcoal/near-black backgrounds, electric accents, subtle gradients, highly premium.
- **Retro / Y2K:** Neon gradients, pixel fonts, hot pink/cyan, 90s aesthetic.
- **Claymorphism / 3D UI:** Inflated, puffy elements, multi-layer shadows, candy colors.

## 2. Scroll & Animation
- **Parallax:** Different layers scrolling at different speeds for depth.
- **Scroll-Triggered:** Fade up and stagger elements as they enter the viewport.
- **Horizontal Scroll:** Pinned vertical scroll that translates to horizontal movement.
- **Sticky Sections:** Sticky visuals with scrolling text.
- **Text Reveal:** Word-by-word or char-by-char reveals.
- **Smooth Scroll (Lenis):** Buttery physics-based momentum scrolling.

## 3. Layouts
- **F-Pattern / Z-Pattern:** Strategic content placement based on eye-tracking.
- **Hero + Feature Grid:** The ultimate SaaS standard layout.
- **Asymmetric / Split:** 60/40 splits for dynamic visual tension.
- **Masonry:** Organic, varied-height grids for galleries.
- **Full-Page Scroll:** Snap-scrolling presentation style.
- **Sidebar + Content:** Standard dashboard/app layout.

## 4. Navigation
- **Sticky Navbar:** Frosted glass on scroll.
- **Hamburger Menu:** Fullscreen animated overlays for mobile.
- **Mega Menu:** Multi-column dropdowns for complex routing.
