The problem this solves

Context exhaustion is the #1 killer of productive AI coding sessions. MEMORY eliminates it at the architectural level.

"It's 3 AM. Your agent has been coding for 6 hours. Then context budget exhausts. It forgets everything — your project structure, auth patterns, conventions. Hallucinations begin." — Every AI developer, eventually

MEMORY replaces the monolithic 3,622-line GEMINI.md with 12 load-on-demand modules backed by a ChromaDB vector database.

Your agent searches first (~200 tokens), loads modules only when search misses (~1,420 tokens full). Result: 60–95% fewer tokens per session.

With the freellmapi proxy routing across 16 free providers, that translates to $0 in API costs for most sessions.

How it works

A deceptively simple architecture that delivers outsized results.

One source of truth

6 symlinks (CLAUDE.md, AGENTS.md, .cursorrules, etc.) all point to one GEMINI.md. Every agent reads the same instructions. No drift.

12 brain modules

Core Rules, CLI Tools, ML Engineering, Security, UI/UX, Web Dev, Job Hunt, Architecture, Misc, Lessons, Errors, Repo Research.

Vector DB first

ChromaDB search returns relevant chunks in ~200 tokens. Modules load only when search misses. 94.2% recall rate across all topics.

0-cost LLM proxy

freellmapi routes across 16 free providers. ~1.7B tokens/month at zero cost. Never pay for API calls again.

54 CLI guardrails

Legacy commands (grep, cat, ls, find, du, ps) auto-routed to modern replacements (rg, bat, eza, fd, dust, procs).

Self-healing

Error → Diagnose → Fix → Re-run → Verify. Pre-commit audits with semgrep, gitleaks, trivy. All symlinks checked.

Architecture

5 agent tools feed into the GEMINI.md router, which lazy-loads from 12 modules. ChromaDB provides vector search for instant recall.

Install in under 2 minutes

One-time setup. Works on macOS, Linux, Windows (WSL).

# Clone & go
git clone https://github.com/adityashirsatrao007/MEMORY.git
cd MEMORY
make hooks # installs git hooks + seeds vector DB
# Symlink for your agent
ln -sf $PWD/GEMINI.md CLAUDE.md # Claude Code
ln -sf $PWD/GEMINI.md .cursorrules # Cursor
Requires: Python 3.10+ · ChromaDB (pip install chromadb) · A terminal
