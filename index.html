The problem this solves

"It's 3 AM. Your agent has been coding for 6 hours. Then context budget exhausts. It forgets everything — your project structure, auth patterns, conventions. Hallucinations begin. You burn money re-explaining."

MEMORY replaces the monolithic 3,622-line GEMINI.md with 12 load-on-demand modules + a vector database for instant recall. Your agent searches first (~200 tokens), loads modules only when needed (~1,420 full). 60-95% fewer tokens per session.

How it works

🔗

One source of truth

6 symlinks (CLAUDE.md, AGENTS.md, .cursorrules, etc.) point to one GEMINI.md. Every agent reads the same instructions.

🧩

12 brain modules

Core Rules, CLI Tools, ML Engineering, Security, UI/UX, Web Dev, Job Hunt, Architecture, Misc, Lessons, Errors, Repos.

🔍

Vector DB first

ChromaDB search returns relevant chunks in ~200 tokens. Modules load only when search misses. 94.2% recall rate.

⚡

0-cost LLM proxy

freellmapi routes across 16 free providers — 1.7B tokens/month. Never pay for API calls again.

🛡️

54 CLI guardrails

Legacy commands (grep, cat, ls, find, du, ps) auto-routed to modern replacements (rg, bat, eza, fd, dust, procs).

🔄

Self-healing

Error → Diagnose → Fix → Re-run → Verify. Pre-commit audits with semgrep, gitleaks, trivy. All 6 symlinks checked.

Install in under 2 minutes

git clone https://github.com/adityashirsatrao007/MEMORY.git
cd MEMORY
make hooks

Then symlink to your agent:

ln -sf $PWD/GEMINI.md CLAUDE.md # for Claude Code
ln -sf $PWD/GEMINI.md .cursorrules # for Cursor

Or symlinks are already included — just point your agent tool at this repo's root.

Requires: Python 3.10+ · ChromaDB (`pip install chromadb`) · A terminal
