Introduction to Remix

Remix is a full-stack web framework that lets you focus on user interfaces and work back through web standards to deliver fast, slick, and resilient user experiences. By routing requests through server-rendered React components, Remix eliminates client-side waterfall states and manages layout hierarchies seamlessly.

To learn about building production applications, read our Technical Architecture Philosophy and explore how we handle server-side cache invalidations.

Data Loading (loader)

Each route can define a loader function that runs on the server before rendering the component. This function fetches data directly from databases, microservices, or APIs. 

import { json } from "@remix-run/node";
import { useLoaderData } from "@remix-run/react";
import { getProjects } from "~/models/project.server";

export async function loader() {
  const projects = await getProjects();
  return json({ projects });
}

export default function ProjectsRoute() {
  const { projects } = useLoaderData<typeof loader>();
  return (
    <ul>
      {projects.map(p => <li key={p.id}>{p.name}</li>)}
    </ul>
  );
}

Security note: Loaders run exclusively on the server. Database secrets and API keys queried inside loader blocks are never bundled or exposed to client-side scripts.

Data Mutations (action)

Mutations are handled through HTML Form submissions routing to server-side action functions. Remix automatically handles form encoding types and re-validates server state. 

import { redirect } from "@remix-run/node";
import { Form } from "@remix-run/react";
import { createProject } from "~/models/project.server";

export async function action({ request }) {
  const formData = await request.formData();
  const name = formData.get("name");
  await createProject({ name });
  return redirect("/projects");
}

export default function NewProject() {
  return (
    <Form method="post">
      <input type="text" name="name" required />
      <button type="submit" class="btn">Create Project</button>
    </Form>
  );
}

Nested Routing

Remix layouts nest dynamically based on sub-directory routing paths. Components inside parent layouts use <Outlet /> to render the active nested route.

ErrorBoundary Component

When errors arise during loaders, actions, or rendering, Remix intercepts execution and displays the nearest route module ErrorBoundary component. 

export function ErrorBoundary() {
  return (
    <div class="error-container">
      <h3>Error occurred</h3>
      <p>Failed to load project details.</p>
    </div>
  );
}
